CodePic turns a code snippet into a clean image for a post, a slide or a pull request. Paste the code, pick a theme and a background, and download a PNG, an SVG, an animated GIF or an MP4 video. The highlighting, the layout and the export all run in the browser. It has no accounts and no server, so the code is never uploaded.

Click a line number to highlight that line, or to mark it as added or removed for a diff view. Box or underline part of a line and add a short note. One image can hold up to three code panels. A share link packs the code and the settings into the URL itself, and a small command line tool draws the same image without opening a browser.

It is built with Svelte 5 and TypeScript, and the highlighting is Shiki. It started as a way to learn Svelte 5.
